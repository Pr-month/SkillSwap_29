# SkillSwap - Платформа для обмена навыками

SkillSwap - это веб-платформа, которая позволяет пользователям обмениваться навыками и знаниями. 
Проект разработан в рамках курса Яндекс.Практикума.

## 🚀 Технологии

- **Next.js** - React-фреймворк для создания веб-приложений
- **TypeScript** - статическая типизация для JavaScript
- **Tailwind CSS** - утилитарный CSS-фреймворк
- **React Hook Form** - управление формами
- **Zod** - валидация данных
- **RTK Query** - управление состоянием и кэширование
- **Shadcn/ui** - компоненты интерфейса

## 📋 Требования

- Node.js 20.0.0 или выше
- pnpm

## 🛠️ Установка и запуск

1. **Клонируйте репозиторий**
   ```bash
   git clone https://github.com/your-username/SkillSwap_29.git
   cd SkillSwap_29/frontend
   ```

2. **Установите зависимости**
   ```bash
   pnpm install
   ```

3. **Настройте переменные окружения**
   Создайте файл `.env.local` в корне фронтенд-части и настройте необходимые переменные:
   ```
   NEXT_PUBLIC_API_URL=http://localhost:3000
   NEXTAUTH_URL=http://localhost:3080
   NEXTAUTH_SECRET=ваш_секретный_ключ
   ```

4. **Запустите сервер разработки**
   ```bash
   pnpm dev
   ```

5. **Откройте в браузере**
   Приложение будет доступно по адресу [http://localhost:3080](http://localhost:3080)

## 📂 Структура проекта

```
frontend/
├── app/                 # Страницы и роуты приложения
│   ├── (auth)/          # Роуты аутентификации
│   ├── (main)/          # Основные страницы приложения
│   ├── (protected)/     # Защищенные роуты
│   ├── error.tsx        # Обработка ошибок
│   ├── layout.tsx       # Основной макет
│   └── loading.tsx      # Компонент загрузки
├── components/          # Переиспользуемые UI-компоненты
│   ├── ui/              # Базовые компоненты интерфейса (Shadcn)
│   └── ...
├── lib/                 # Утилиты и конфигурации
├── store/               # Хранилище состояний (Redux)
├── styles/              # Глобальные стили
├── public/              # Статические файлы (изображения, иконки)
├── hooks/               # Кастомные React-хуки
├── middleware.ts        # Next.js middleware
└── next.config.ts       # Конфигурация Next.js
```
