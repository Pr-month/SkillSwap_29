# Скрипты инициализации PostgreSQL

В этой директории находятся SQL-скрипты для инициализации базы данных SkillSwap с тестовыми данными.

## Файлы

- [init-categories.sql](init-categories.sql) - Создание иерархии категорий
- [init-users.sql](init-users.sql) - Создание тестовых пользователей и администратора
- [init-skills.sql](init-skills.sql) - Создание навыков и связей пользователь-навык
- [test-seed.sql](test-seed.sql) - Скрипт для проверки тестовых данных
- [clear-seed.sql](clear-seed.sql) - Скрипт для очистки всех тестовых данных
- [verify-tables.sql](verify-tables.sql) - Скрипт для проверки структуры таблиц
- [reset-db.sh](reset-db.sh) - Bash-скрипт для сброса базы данных

## Использование

Эти скрипты автоматически выполняются при первой инициализации контейнера PostgreSQL. Важен порядок выполнения:

1. init-categories.sql
2. init-users.sql
3. init-skills.sql

## Интеграция с Docker

Файл docker-compose.yml настроен на автоматический запуск этих скриптов при первом запуске контейнера с базой данных. Скрипты выполняются в алфавитном порядке, поэтому они имеют префикс `init-`.

## Обзор данных

### Категории
- 4 родительские категории: IT и программирование, Дизайн, Маркетинг и реклама, Хобби
- Всего 13 подкатегорий

### Пользователи
- 5 тестовых пользователей с ролью USER
- 1 пользователь с ролью ADMIN
- У всех пользователей хешированные пароли (user123 для обычных пользователей, admin123 для администратора)

### Навыки
- 6 навыков, распределенных между пользователями
- Связи пользователь-навык для "могу научить" и "хочу изучить"

## Пароли

В целях безопасности все пароли хранятся в виде bcrypt-хешей:
- Пароль обычного пользователя: `user123`
- Пароль администратора: `admin123`

В продакшн-среде рекомендуется изменить эти пароли и использовать переменные окружения для конфиденциальных данных.

## Проверка

Вы можете проверить корректность вставки данных, запустив скрипт [test-seed.sql](test-seed.sql):

```sql
psql -U postgres -d skillswap -f test-seed.sql
```

Для проверки структуры таблиц выполните скрипт [verify-tables.sql](verify-tables.sql):

```sql
psql -U postgres -d skillswap -f verify-tables.sql
```

Для очистки всех тестовых данных (в целях тестирования) выполните скрипт [clear-seed.sql](clear-seed.sql):

```sql
psql -U postgres -d skillswap -f clear-seed.sql
```

## Сброс базы данных

Для полного сброса базы данных и повторного заполнения свежими данными выполните скрипт [reset-db.sh](reset-db.sh):

```bash
./reset-db.sh
```

Этот скрипт:
1. Остановит все докер-контейнеры
2. Удалит том базы данных (со всеми данными)
3. Перезапустит контейнеры
4. Скрипты инициализации автоматически выполнятся при запуске базы данных
