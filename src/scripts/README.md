# Заполнение базы данных начальными данными (Seeding)

В этой директории находятся скрипты для первоначального заполнения базы данных тестовыми данными. Эти скрипты предназначены для создания пользователей, категорий и навыков, необходимых для разработки и тестирования приложения.

## Порядок выполнения скриптов

Для корректного заполнения базы данных и установки всех необходимых связей между сущностями, скрипты необходимо выполнять в строгой последовательности:

1.  **`seed-users.ts`** - Создает пользователей, включая администратора.
2.  **`seed-categories.ts`** - Создает иерархию категорий и подкатегорий.
3.  **`seed-skills.ts`** - Создает навыки и связывает их с существующими категориями и пользователями.

Эта последовательность важна, так как навыки зависят от категорий и пользователей.

## Как запустить

### 1. Загрузка пользователей

```sh
npx ts-node seed-users.ts
```

### 2. Загрузка категорий

```sh
npx ts-node seed-categories.ts
```

### 3. Загрузка навыков

```sh
npx ts-node seed-skills.ts
```

## Важные замечания

*   **Конфигурация:** Перед запуском убедитесь, что конфигурация подключения к базе данных в `src/config/ormconfig.ts` верна и сервер базы данных доступен.
