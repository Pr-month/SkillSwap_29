# Скрипты для заполнения базы данных (Seeding)

В этой директории находятся скрипты для первоначального заполнения базы данных тестовыми данными. Эти скрипты предназначены для создания пользователей, категорий и навыков, необходимых для разработки и тестирования приложения.

## Порядок выполнения скриптов

Для корректного заполнения базы данных и установки всех необходимых связей между сущностями, скрипты необходимо выполнять в строгой последовательности:

1. **`seed-admin.ts`** - Создает администратора системы (для production)
    - Использует переменные окружения из `.env`
2.  **`seed-users.ts`** - Создает тестовых пользователей (только для разработки/тестирования)
3.  **`seed-categories.ts`** - Создает иерархию категорий и подкатегорий.
    - Использует данные из отдельного файла `seed-categories.data.ts`
4.  **`seed-skills.ts`** - Создает навыки и связывает их с существующими категориями и пользователями.
    - Использует данные из отдельного файла `seed-skills.data.ts`

Эта последовательность важна, так как навыки зависят от категорий и пользователей.

## Запуск скриптов

### Создать администратора
```bash
npm run seed:admin
```

### Создать тестовых пользователей (только для разработки)
```bash
npm run seed:users
```

### Создать категории
```bash
npm run seed:categories
```

### Создать навыки
```bash
npm run seed:skills
```

### Запустить все скрипты последовательно
```bash
npm run seed:all
```

### Важные замечания

#### Креды администратора
```
ADMIN_EMAIL=admin@skillswap.com
ADMIN_PASSWORD=your_secure_password
```

*   **Конфигурация:** Перед запуском убедитесь, что конфигурация подключения к базе данных в `src/config/ormconfig.ts` верна и сервер базы данных доступен.
